# RAKSHA Privacy By Design Specification

## Data Protection Commitments

1. **No Sensitive Record Access**: RAKSHA does NOT request or access user bank account credentials, OTPs, SMS inboxes, brokerage logins, passwords, or personal portfolio records.
2. **Ephemeral Upload Processing**: User screenshots and voice notes are processed in memory or stored temporarily in local temporary directories during investigation execution.
3. **Data Deletion Control**: Users can clear investigation history and delete audit records from the local SQLite / PostgreSQL database.
4. **No Third-Party Commercial Tracking**: No user data is sold, monetized, or shared with third-party advertisers.
